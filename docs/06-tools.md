# 06 — Tools

## Data & forecast

- **[Open-Meteo](https://open-meteo.com/)** — ensemble gratis (GEFS 31-member,
  ECMWF, ICON). **Inti workflow.**
- **[Windy](https://www.windy.com/)** — visualisasi multi-model.
- **[Pivotal Weather](https://www.pivotalweather.com/)** — peta model detail.

## Blend forecast + harga market (cari divergence)

Tools yang nge-overlay forecast ke harga market buat nyari gap:

- **Weather Edge Finder**
- **vweatherstation**
- **OutcomeEdge**

Fungsinya: blend forecast + harga market → sorot divergence (kandidat edge).

## Cross-venue / arbitrase

- **Oddpool** — bandingin Polymarket + Kalshi, cari arb, data historis.

## Kurasi

- **Awesome-Prediction-Market-Tools** (GitHub) — daftar terkurasi tools & API
  prediction market.

## Macro (bukan weather, tapi berguna)

- **CME FedWatch** — untuk market macro (rate), **bukan** untuk weather. Dicantumin
  biar gak ketuker.

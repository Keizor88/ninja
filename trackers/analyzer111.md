# analyzer111 — Template Memo Institusional (12 seksi)

**Trigger:** `analyzer111 <asset>`
**Fungsi:** kerangka analisa 1 aset gaya memo institusional.

---

## Struktur 12 Seksi

1. **Ringkasan / Tesis** — 1-2 kalimat, skor konviksi (x/10).
2. **Apa ini** — produk, kategori, value-prop.
3. **Katalis** — event/listing/upgrade yang bisa gerakin harga.
4. **On-chain / Fundamental** — TVL, revenue, users, token flow.
5. **Tokenomics** — supply, emisi, unlock schedule, buyback.
6. **Valuasi** — vs peer, vs history (mahal/murah).
7. **Struktur pasar** — likuiditas, funding, spot vs futures.
8. **Narasi vs Value** — attention ≠ value check.
9. **Skenario** — bull / base / bear + probabilitas.
10. **Entry plan** — zona akumulasi, ladder, di flush.
11. **Exit / target** — ladder jual, invalidasi.
12. **Risk / tripwire** — apa yang batalin tesis.

*Isi tiap seksi pas dipanggil `analyzer111 <asset>` dengan data live.*
